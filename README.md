# Собери заказ

Браузерная мини-игра для детей 7+: выбери предмет → Ctrl/⌘ + D → получи копию.

## Файлы проекта

- [Исходный проект](order-workshop-source.zip) — React, TypeScript, Vite, 10 заказов, все PNG и MP3, тесты и подробная инструкция.
- [Готовая сборка](order-workshop-dist.zip) — распакуйте на статическом веб-сервере для запуска и встраивания в iframe.

Исходники размещены архивом, поскольку текущая GitHub-авторизация для Git/API не разрешает запись. Архив загружен через веб-интерфейс владельца репозитория.

## Запуск исходников

Распакуйте `order-workshop-source.zip`, затем выполните в полученной папке:

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Проверки: `npm test` (требуется Google Chrome).

## Игра

10 заказов, 33 дублирования, 830 очков за полное прохождение. Есть стартовый и финальный экраны, подсказки, выбор предметов, музыка и звуки, перезапуск, адаптивная вёрстка.

Графика и звуки: `public/assets/`. Настройки и заказы: `src/order-game/data.ts`.

Проверены полный цикл внутри iframe, Ctrl/⌘ + D, русская раскладка, ошибки выбора, 4 автоматических теста и production-сборка.
