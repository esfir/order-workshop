# Собери заказ

Браузерная мини-игра для детей 7+: выбрать предмет → Ctrl/⌘ + D → получить копию. React + TypeScript + Vite. Без маскотов и привязки к школе.

## Запуск

```sh
npm install
npm run dev
npm run build
npm run preview
npm test
```

`dist/` — готовая статическая сборка. Относительные пути позволяют разместить её в любом подкаталоге. Браузерные тесты используют установленный Google Chrome.

## Встраивание

```html
<iframe src="https://your-host.example/order-game/" title="Собери заказ"
  width="1024" height="600" style="border:0" allow="autoplay"></iframe>
```

Для sandbox-iframe требуется `allow-scripts`; политика хоста должна разрешать загрузку JS, изображений и аудио. Нажатие «Играть» и выбор предмета возвращают фокус игре. Горячая клавиша перехватывается только во время игры и только когда клавиатурный фокус находится внутри её документа. Если фокус у родительской страницы или адресной строки, iframe не может перехватить сочетание. Физическая клавиша D распознаётся и в русской раскладке. Удерживание клавиши не создаёт дополнительные копии.

## Настройка

- `src/order-game/data.ts`: `gameConfig`, подписи предметов, состав десяти заказов.
- `src/order-game/engine.ts`: чистая игровая механика, очки, защита от лишних копий.
- `src/order-game/audio.ts`: звук, музыка, синтезированный резервный звук.
- `src/order-game/visuals.tsx`: изображения, клавиши, конфетти.
- `src/App.tsx`: экраны, фокус, клавиатура, постепенное уменьшение подсказок.
- `src/styles/global.css`: адаптивная вёрстка и анимации, reduced-motion.
- `public/assets/`: PNG и MP3, доступные без внешних сервисов.

`gameConfig` содержит `gameTitle`, `schoolName`, `logoUrl`, `accentColor`. Без логотипа пустое место не резервируется. При необходимости изменяйте конфиг до сборки.

В каждом заказе уже есть один предмет каждого требуемого типа. Поэтому десять заказов требуют **33 дублирования**, итоговый счёт **830**: 330 за копии и 500 за заказы. Штрафов нет. После завершения заказ автоматически сменяется через 1,9 секунды. Продолжительность зависит от ребёнка: принудительной задержки на 5–7 минут нет.

Заказы 1–2: крупная постоянная подсказка; 3–5: компактная; 6–8: после 6,5 секунд бездействия; 9–10: после 12 секунд. Доступна кнопка «Напомнить клавиши».

Музыка по умолчанию выключена; её кнопка независима от общего выключателя звука. Аудио начинает играть после пользовательского действия. Все 11 MP3 сгенерированы локальным синтезом и включены в проект. Если MP3 недоступен, SFX используют Web Audio.

## Графика

Восемь предметов и три фона созданы встроенным imagegen, промпты сохранены в `public/assets/asset-prompts.md`. Предметы содержат настоящий альфа-канал. Панели, кнопки, иконки, клавиши и эффекты экспортированы в PNG из согласованной геометрии (`npm run assets`). В интерфейсе панели, текст кнопок и клавиши собраны в HTML/CSS для адаптивности и доступности; PNG-версии доступны для повторного использования.

## Проверки

`tests/game.spec.ts`: расчёт всех десяти заказов, 33 копий и 830 очков; ошибки и переполнение; полный проход внутри iframe с Ctrl и Command; русская раскладка; предотвращение стандартного события; перезапуск; размеры 1024×600, 640×600, 390×844; отсутствие ошибок JavaScript.

Ранее существовавшие неиспользуемые сцены сохранены, чтобы не уничтожать исходную работу. Точка входа использует только новую игру.
